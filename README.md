## Project Overview

Green AI Dashboard is a modern, interactive sustainability platform designed to promote green computing, carbon-neutral technology, and energy awareness.
With a sleek, animated UI, floating 3D leaves, and real-time charts, this dashboard simplifies carbon tracking and empowers users to make eco-friendly choices in the world of tech.

 ## Key Features
 
 ### 1. PC Carbon Footprint Calculator

• Calculates daily CO₂ emissions based on power usage  
• Helps users track energy consumption  
• Simple and accurate kWh-to-carbon estimation  

### 2. AI Model Energy Checker
    
• Estimates energy usage of ML models  
• Logistic Regression → Large Neural Networks  
• Helps developers build greener AI  

### 3. Website Carbon Analyzer
   
• Estimates CO₂ emissions per website visit  
• Lightweight & instant analysis  
• Encourages low-carbon web design  

### 4. Green Reminder Bot
   
• Sends hourly eco-reminders  
• Encourages power saving habits  
• Fully browser-based 

### 5. Carbon Emission Charts
   
• Daily, Weekly, Monthly breakdown  
• Switch chart type (Line / Bar / Pie)  
• Interactive Chart.js visualization
